# 健康监测「生活节奏轴」UI 落地规范

日期：2026-06-21
状态：已选定视觉方向，待 Flutter 实现

## 1. 目标

本规范把已选定的方案 2「生活节奏轴」转换为可测量、可测试、可直接落地到 Flutter 的界面约束。

视觉参考：

- `docs/designs/health-monitor-daily-rhythm-reference.png`

本轮首页继续遵守以下产品原则：

- 温和陪伴，不制造健康焦虑
- 先给结论，再解释依据
- 不做医学诊断，不展示未经产品定义的医学指标
- 页面层只消费聚合后的 UI 数据，不直接消费原始传感器数据

## 2. 还原标准

### 2.1 “1:1”在本项目中的定义

Flutter 实现以 `390 × 844 dp` 为设计基准，验收时至少对齐：

- 页面区块顺序与视觉重心
- 左右边距、区块间距、卡片高度和圆角
- 字号、字重、行高与文字换行位置
- 主色、状态色、背景渐变和边框透明度
- 图标视觉尺寸、线宽、容器尺寸与对齐方式
- 节奏轴曲线、节点位置、当前时刻标记和趋势线走势
- 底部导航高度、激活态尺寸与安全区

不把生成图中的像素噪声、轻微文字渲染差异和不可复用的 AI 图形误差视为必须复刻的设计属性。

### 2.2 设计基准

- 设计画板：`390 × 844`
- 页面横向安全边距：`18`
- 主内容最大宽度：`354`
- 基础间距单位：`4`
- 页面滚动：允许纵向滚动
- 底部导航：固定悬浮，并为正文预留底部空间

参考图本身是放大渲染图，Flutter 实现不得直接按图片像素尺寸硬编码，应按上述逻辑尺寸还原。

## 3. 页面结构

首页从上到下分为六个区域：

1. 问候与个人感知入口
2. 日间节奏轴
3. 今日结论与状态分
4. 四维健康摘要
5. 当前行动建议
6. 悬浮底部导航

### 3.1 页面头部

- 页面标题：`今天的节奏`
- 标题字号：`30`
- 标题字重：`FontWeight.w700`
- 副标题：`身体没有催你，只是在提醒你换个姿势`
- 副标题字号：`14`
- 副标题行高：`1.45`
- 右侧入口：`个人感知`
- 入口高度：`40`
- 入口水平内边距：`14`
- 入口圆角：`20`
- 图标与文字间距：`8`

个人感知入口应沿用现有能力与权限入口，不新增无业务承接的页面。

### 3.2 日间节奏轴

节奏轴是本方案的主要差异点，应使用 Flutter `CustomPainter` 绘制，不使用位图。

结构包括：

- 一条从左下向中部抬升、再向右下回落的柔和弧线
- 早晨与晚间的起止图标
- 四个事件节点
- 当前时刻强调节点
- 节点上方的时间、状态与维度图标

固定示例节点：

| 时间 | 状态 | 维度 | 色彩 |
| --- | --- | --- | --- |
| 09:00 | 活动良好 | 活动 | 鼠尾草绿 |
| 14:30 | 久坐集中 | 姿势 | 暖沙色 |
| 18:00 | 噪音偏高 | 环境 | 柔和珊瑚色 |
| 21:00 | 看屏频繁 | 数字习惯 | 雾蓝色 |

绘制约束：

- 节奏轴区域建议高度：`176`
- 曲线线宽：`1.5`
- 默认曲线色：`#9BA19B`
- 彩色区间透明度：`0.65`
- 普通节点直径：`8`
- 普通节点外圈直径：`16`
- 当前节点外圈直径：`30`
- 当前节点中心直径：`10`
- 当前节点主色：`#F0A23B`
- 图标容器：`32 × 32`
- 图标容器圆角：`16`
- 图标视觉尺寸：`18`
- 时间字号：`12`
- 状态字号：`12`
- 当前时间文案字号：`12`

事件节点位置由可用宽度按比例计算，不能使用只适配单一设备宽度的绝对屏幕坐标。

### 3.3 今日结论

结论区是一张单层主卡，不允许再嵌套完整卡片。

- 卡片圆角：`28`
- 内边距：`18`
- 背景：`#FFFFFF`
- 边框：`#DDD8CF`，透明度约 `0.72`
- 阴影：黑色 `8%`，模糊 `24`，Y 偏移 `8`
- 主结论：`整体平稳，下午需要一次短暂活动`
- 主结论字号：`20`
- 主结论字重：`FontWeight.w700`

状态分位于右侧独立视觉区，但只使用轻微底色分隔，不绘制第二层厚重卡片：

- 标签：`今日状态`
- 分数：`82`
- 标签字号：`12`
- 分数字号：`42`
- 分数字重：`FontWeight.w600`
- 分数色：`#6F9A72`
- 状态强调点：`#F0A23B`

窄屏或系统大字体下，状态分移到主结论下方，禁止压缩主结论到不可读宽度。

### 3.4 四维健康摘要

四维数据放在同一个分组表面中，通过行分隔线区分，不拆成四张独立卡片。

每行结构：

1. 维度图标
2. 维度名与主要数值
3. 微型趋势线
4. 状态结论与辅助说明
5. 详情箭头

统一尺寸：

- 分组圆角：`28`
- 分组内边距：水平 `16`
- 单行最小高度：`72`
- 分隔线：`#EAE5DC`
- 图标容器：`34 × 34`
- 图标尺寸：`19`
- 维度名字号：`13`
- 主数据字号：`20`
- 单位字号：`12`
- 状态字号：`14`
- 辅助说明字号：`12`
- 趋势线区域：约 `92 × 34`
- 趋势线宽：`1.8`

数据示例：

| 维度 | 主数据 | 状态 | 辅助说明 |
| --- | --- | --- | --- |
| 活动 | `6,240 步` | 良好 | 比昨日多 12% |
| 姿势 | `久坐 3.2 小时` | 专注时段 | 14:00–16:30 |
| 环境噪音 | `48 dB` | 偏高 | 傍晚时段 |
| 数字习惯 | `看屏 2.8 小时` | 偏多 | 晚间时段 |

无数据时必须显示真实降级态，不绘制虚假趋势。

### 3.5 行动建议

行动建议使用一张暖色强调卡：

- 标题：`现在起身活动 3 分钟`
- 说明：`不用补运动量，先打断久坐就够了`
- 卡片圆角：`28`
- 卡片最小高度：`92`
- 背景：`#FFFFFF`，通过橙色图标容器与按钮表达行动强调
- 标题字号：`18`
- `3` 使用柔和橙 `#E59A3A`
- 操作按钮：`44 × 44`
- 按钮色：`#F0A23B`
- 按钮图标：向右箭头

参考图中的人物插画不是功能必需资产。首版落地建议：

- 不直接裁切生成图中的人物
- 使用现有真实授权插画时再接入
- 没有合适插画时，用留白与轻量背景光晕完成构图

### 4.3 动效

- 页面进入：沿用 `HealthStaggeredEntrance`
- 节奏轴节点：仅在首次进入时轻淡入，不做循环动画

- 遵守系统“减少动态效果”设置

## 5. 图标还原策略

Figma 不是实现这些图标的必要条件。首版统一使用 Flutter Material Symbols/Rounded 图标，避免混用多套线宽。

建议映射：

| 语义 | Flutter 图标候选 |
| --- | --- |
| 个人感知 | `Icons.person_outline_rounded` |
| 活动 | `Icons.directions_walk_rounded` |
| 姿势/座椅 | `Icons.chair_alt_rounded` |
| 环境噪音 | `Icons.graphic_eq_rounded` |
| 数字习惯 | `Icons.phone_iphone_rounded` |
| 早晨 | `Icons.wb_sunny_outlined` |
| 晚间 | `Icons.dark_mode_outlined` |
| 首页 | `Icons.home_outlined` |
| 趋势 | `Icons.show_chart_rounded` |
| 简报 | `Icons.article_outlined` |
| 我的 | `Icons.person_outline_rounded` |
| 进入详情 | `Icons.chevron_right_rounded` |
| 行动 | `Icons.arrow_forward_rounded` |

统一视觉参数：

- 默认图标使用 Rounded 风格
- 功能图标线性视觉尺寸为 `18–22`
- 图标容器使用维度色的浅色背景
- 同一级图标不能混用实心与线性风格

只有以下情况才新增 SVG：

- Material Symbols 无法表达语义
- 同一图标在设计验收中出现明显轮廓差异
- 品牌专属图形或插画需要独立版权资产

若新增 SVG，应放在 `assets/icons/common/`，并在 `pubspec.yaml` 中显式登记。Android/iOS 专属图标必须进入对应平台目录，不得混入 common。

## 6. 自绘图形边界

以下内容使用 `CustomPainter`，不依赖 Figma 导出：

- 日间弧形节奏轴
- 节奏轴节点和当前时刻光环
- 四维摘要中的微型趋势线

Painter 输入必须是轻量 UI 参数，例如：

- 标准化节点位置
- 状态色
- 当前节点索引
- 标准化趋势值列表

Painter 不得直接读取 provider、领域仓库或原始传感器数据。

## 8. 验证方式

实现后至少执行：

1. `390 × 844` 基准尺寸截图
2. 与参考图并排视觉比较
3. `360 × 800` 小屏检查
4. 大字体模式检查
5. 无步数、无 Usage Access、无噪音样本的降级态检查
6. 首页现有点击入口与字段级刷新测试

视觉验收优先级：

1. 信息层级与可读性
2. 布局尺寸与对齐
3. 色彩、圆角与图标一致性
4. 曲线与细节装饰

## 9. 结论

方案 2 不依赖 Figma 才能落地。大部分图标可由统一的 Flutter Rounded 图标体系高质量还原；真正需要精确控制的节奏轴与趋势线应直接用 `CustomPainter` 绘制。

Figma 的价值主要是团队协作、标注和视觉评审，而不是 Flutter 实现的技术前置条件。按本规范实现并进行同尺寸截图校准，可以达到接近设计稿的生产级还原效果。
